# Skin

An interactive skincare showcase built with React, TypeScript, Vite, and React Three Fiber.

## Development

```sh
npm ci
npm run dev
```

## Validation

```sh
npm run build
npm run verify:flow
```

## Vercel deployment

Import this repository into Vercel with the Vite framework preset. Use `npm run build` as the build command and `dist` as the output directory.
